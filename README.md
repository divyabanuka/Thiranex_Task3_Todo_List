# 🚀 TaskFlow – To-Do List

A responsive and interactive To-Do List application developed for **Thiranex Task 3 – JavaScript Logic & State Management**.

## 📌 Project Overview

TaskFlow is a client-side task management application built using HTML, CSS, and JavaScript.

The project demonstrates JavaScript DOM manipulation, event handling, CRUD operations, task filtering, state management, and browser data persistence using localStorage.

## ✨ Features

- ➕ Add new tasks
- 👀 View all tasks
- ✏️ Edit existing tasks
- 🗑️ Delete tasks
- ☑️ Mark tasks as completed
- 🔄 Mark completed tasks as active
- 🔍 Filter tasks by All, Active, and Completed
- 🧹 Clear completed tasks
- 💾 Save tasks automatically using localStorage
- 🔄 Tasks remain after browser refresh
- 📱 Responsive design for mobile and desktop
- ⚡ Dynamic DOM manipulation
- 🖱️ Event handling and event delegation

## 💾 LocalStorage

The application uses browser `localStorage` to save tasks.

This allows tasks to remain available even after refreshing the webpage.

## ▶️ How to Use

1. Open the Live Demo.
2. Enter a task in the input field.
3. Click **Add Task**.
4. Use the checkbox to mark a task as completed.
5. Use **Edit** to modify a task.
6. Use **Delete** to remove a task.
7. Use **All**, **Active**, and **Completed** filters.
8. Refresh the browser to verify that tasks are saved using localStorage.
